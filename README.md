# 666 - 局域网文件传输

> 极简、高速、安全的局域网文件互传工具 —— 无需数据线，无需上传云端，同一网络下的设备直接互传。

## 📖 项目简介

**666** 是一款专注于**局域网文件传输**的工具。只要两台设备连接同一个 Wi-Fi 或同一路由器，即可互相发现并高速传输文件，全程不经过互联网，数据不出内网。

适用于：

- 📱 手机 ↔ 电脑：传照片、视频、文档，告别数据线和聊天软件传文件
- 💻 电脑 ↔ 电脑：办公环境大文件快速分发
- 📺 电脑/手机 ↔ 电视、平板：多媒体文件秒传

## ✨ 功能特性

| 特性 | 说明 |
| --- | --- |
| ⚡ 高速传输 | 走局域网直连，速度仅受路由器带宽限制，百兆内网可达 10MB/s+ |
| 🔍 自动发现 | 基于 mDNS / UDP 广播自动发现同网段设备，无需手动输入 IP |
| 📱 扫码连接 | 接收端展示二维码，手机扫码即连 |
| 📂 支持文件夹 | 整个文件夹打包传输，保持目录结构 |
| ⏸️ 断点续传 | 大文件传输中断后可从断点继续 |
| 🔒 隐私安全 | 数据全程在内网传输，不上传云端，不留服务器痕迹 |
| 🌈 跨平台 | Windows / macOS / Linux / Android / iOS 全平台支持 |

## 🚀 快速开始

### 环境要求

- 所有设备处于**同一局域网**（同一 Wi-Fi 或同一路由器下）
- 路由器未开启「AP 隔离」

### 安装与运行

```bash
# 克隆仓库
git clone https://github.com/david88558855/666.git
cd 666

# 安装依赖
npm install

# 启动服务
npm start
```

启动后终端会显示本机地址，例如 `http://192.168.1.100:8080`。

## 📖 使用方法

### 发送端

1. 启动程序，选择要发送的文件或文件夹
2. 程序自动列出同网段在线设备
3. 选择目标设备，点击发送

### 接收端

1. 打开程序进入接收模式
2. 屏幕显示二维码（或直接访问显示的地址）
3. 确认后文件自动开始接收，完成后可直接打开所在目录

## 🔧 工作原理

```
┌──────────────┐   1. mDNS/UDP 广播发现    ┌──────────────┐
│   发送设备    │ ────────────────────────▶ │   接收设备    │
│              │                           │              │
│              │   2. 建立 TCP 直连         │              │
│              │ ◀──────────────────────── │              │
│              │                           │              │
│              │   3. 分块流式传输文件       │              │
│              │ ────────────────────────▶ │              │
└──────────────┘      （校验 + 断点续传）    └──────────────┘
```

1. **设备发现**：通过 mDNS 或 UDP 广播在同网段内宣告自己的存在
2. **建立连接**：发现设备后建立 TCP 直连通道
3. **分块传输**：文件分块流式传输，附带 MD5 校验，支持断点续传

## 🔒 安全性说明

- 所有数据仅在局域网内点对点传输，**不经过任何服务器**
- 传输通道可开启端到端加密，防止同网段抓包
- 每次传输需接收端确认，避免被恶意投递

## ❓ 常见问题

**Q: 搜索不到其他设备？**

A: 请确认两台设备连接同一 Wi-Fi；检查路由器是否开启了「AP 隔离 / 访客网络隔离」，开启后设备间无法互访；尝试关闭手机流量。

**Q: 传输速度慢？**

A: 速度取决于路由器性能，尽量让两台设备都连接 5GHz Wi-Fi，或其中一台使用网线。

**Q: 需要联网吗？**

A: 不需要。整个传输过程完全在局域网内完成。
