项目介绍

项目 gostc-rs —— 用 Rust 重写的内网穿透管理平台（gostc-open 的 Rust 复刻版）
管理面蓝本 SianHH/gostc-open：面板布局 / 交互 / 术语全面对齐
数据面蓝本 orbien-org/orbien：隧道协议与传输层直接复用（client 库级嵌入 + server 子进程托管，Phase 3）
P2P 原理参考 EasyTier：STUN 探测 + UDP 打洞 + 节点中继回退 + 延迟优先选路
源码 github.com/david88558855/666 · 架构文档 ARCHITECTURE.md
许可证 Apache-2.0

架构与组件

连接模型 节点 / 客户端都只连中央控制台，启动没有先后；绑定关系在隧道上，配置约 30 秒内自动下发
gostc-rs-admin 管理后端：REST API + 内嵌 Web 面板（SQLite + sqlx 自动迁移）
gostc-rs-tunnel-server 隧道服务端：监听客户端反向连接、按需开放公网端口（部署在有公网 IP 的机器）
gostc-rs-tunnel-client 隧道客户端：部署在内网机器，反向连接 + 内置 STUN 公网映射探测（Phase 4 接入打洞）

使用流程（与 gostc 一致，全程 Web 配置）

第一步 「节点管理」新建节点，复制运行命令到公网服务器：gostc-rs-tunnel-server --api http://面板:8080 --secret <节点Secret>
第二步 「客户端」新建客户端（无需选节点），复制命令到内网机器：gostc-rs-tunnel-client --api http://面板:8080 --token <客户端Token>
第三步 隧道页新建隧道（选客户端 + 节点、类型、内网目标），启用后自动下发、无需重启；秘密 / P2P 隧道再在「更多操作 → 访客管理」为访问方客户端添加本地监听入口
